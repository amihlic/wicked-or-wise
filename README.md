# Wicked or Wise

Corpus metadata for the research project *Wicked or Wise: A Sentiment Analysis of the Representation of Witches and Wizards in Children's Literature*.

## Files

| File | Description |
|---|---|
| `witch_corpus_metadata.csv` | Metadata for the 365 texts featuring witch characters |
| `wizard_corpus_metadata.csv` | Metadata for the 217 texts featuring wizard characters |

## Metadata fields

| Field | Description |
|---|---|
| `book_id` | Unique identifier for the text |
| `title` | Title of the work |
| `author` | Author, editor, or collector |
| `publication_year` | Year of the edition analysed |
| `target_age_group` | Intended reader age group |
| `character_name` | Name of the relevant character(s) |
| `character_term` | Term used in the text, e.g. *witch*, *crone*, *wizard*, *mage* |
